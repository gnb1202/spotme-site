# SPOT ME 오프닝 제작 계획 및 결과

> 현재 비교본은 문서 마지막의 **2026-09-26 추가 수정: 인피니티 미러 v1**이다. 앞부분의 스포츠 포스터/광고 컷은 최초 제작 이력이다.

## 승인된 계획

2026-09-26 승인된 두 방향을 HyperFrames로 먼저 제작한다. A는 고정 구도의 스포츠 포스터, B는 디테일 확대와 컷 전환이 있는 강한 광고 편집이다. 각각 1920×1080, 60fps, 4.5초 무음 영상으로 출력한다. 완성 구도와 마지막 홈 화면은 동일하게 유지한다.

현재 사이트의 Strelka 타이포와 오늘자 바벨 레미를 사용한다. 원본의 형태를 바꾸지 않고 레미 내부를 3단계 흑백으로 단순화하며 민트색 외곽선을 적용한다. 추가 문구, 캐릭터, 사운드, 반복 점멸, 바운스 및 무작위 흔들림은 넣지 않는다.

## 제작 범위와 검증 기준

- 독립 작업 폴더에서만 진행한다. 기존 public과 운영 설정은 변경하지 않는다. 배포·Git push는 하지 않는다.
- HyperFrames 0.8.77과 GSAP 3.15.0을 고정한다. 정지·역방향·임의 탐색이 가능한 단일 타임라인을 사용한다.
- 마스크 질감은 고정 시드를 사용한다. 랜덤 패턴이 재생마다 달라지지 않아야 한다.
- 로컬 비교 페이지, 무음 MP4 두 개, 전환 키프레임, 검증 결과를 제공한다.
- 최종 타이포·레미의 홈 배치 오차는 1px 이하. 마지막 0.85초는 동일 화면이다.
- 마스크 잔여물, 위치 점프, 누락된 에셋·폰트, 콘솔 오류를 검사한다.
- 작업 완료 후 아래에 구현 내용, 실행 명령, 실제 검증 수치, 계획 대비 변경 사항을 한국어로 기록한다.

### 3. 실제 적용한 연출

A는 승인된 시간표를 유지했다. Strelka Ultra의 실제 글리프 경로를 민트색 선으로 그린다. 둘째 줄은 0.18초 늦게 시작하며, 각 줄은 70% 진행 지점에서 0.08초 멈춘다. 1.45초부터 레미의 좌하단에서 우상단으로 톱니 형태의 인쇄 마스크가 지나간다. 레미와 타이포 자체는 이동하거나 확대하지 않는다.

B는 첫째 줄·둘째 줄을 1.35배로 보여준 뒤 원래 타이포 구도로 돌아온다. 1.20초부터 바벨, 1.55초부터 얼굴을 각각 2배 확대 컷으로 보여준다. 1.90초에 원래 레미 구도로 돌아와 마스크를 공개하고, 2.25초부터 A와 같은 완성 포스터를 유지한다.

두 시안 모두 2.65–3.65초에 검정 포스터 레이어를 디졸브한다. 배경으로 보이는 마지막 홈은 캡처 이미지가 아니라 기존 홈의 실제 HTML·CSS·에셋이다. 마지막 0.85초에는 움직임이 없다. 마스크의 거친 경계는 고정 시드 `20260926`으로 생성하며 화면 전체 노이즈나 반복 애니메이션은 추가하지 않았다.

### 6. 발견하고 처리한 문제

1. SVG 선 진행률이 정수 px로 반올림되어 끊겨 보이는 문제를 `autoRound:false`로 수정했다. 70% 정지는 하나의 탐색 가능한 easing 함수로 구현했다.
2. 마스크를 되감았다가 다시 탐색했을 때 합성 방식에 따른 경계 픽셀 차이가 있었다. 마스크의 합성 레이어를 고정해 재탐색 PNG 해시가 일치하도록 수정했다.
3. HyperFrames의 폰트 경로 처리에서 `%20`이 실제 공백으로 해석되지 않았다. 복사본 CSS의 인용부호 안 경로에 공백을 그대로 사용해 Strelka를 정상 포함시켰다. 다른 폰트로 대체하지 않았다.
4. 비교 슬라이더를 연속 조작한 직후 개별 재생하면 이전 탐색이 재생을 멈추는 문제가 있었다. 최신 입력 번호를 기준으로 오래된 작업을 무효화해 수정했다.
5. HyperFrames의 일반 레이아웃 검사기는 외곽선만 있는 투명 채움 타이포를 ‘보이지 않는 텍스트’로 판단했다. 원본에서 의도된 레미 겹침·홈 배경 크롭도 오류로 분류했다. 해당 타이포 하나와 명시적 홈 크롭에만 검사 주석을 넣고, 실제 캡처·좌표 검사로 별도 확인했다. 전체 레이아웃 검사를 끄지는 않았다.

남은 경고: 기존 홈의 우측 `홍보 영상` 메뉴 대비가 3.77:1로 검출되었다. 검사 기준 4.5:1보다 낮다. 이번 작업은 기존 홈 디자인을 유지하는 오프닝 비교이므로 색상을 임의 변경하지 않았다. 실제 사이트 적용 단계에서 배경 또는 글자 대비를 별도로 결정해야 한다. 따라서 ‘접근성 전체 통과’라고 보고하지 않는다.

### 7. 재실행 명령

작업 폴더는 `D:/Github/spotme-site/v3/motion-studies`이다. 새 환경에서는 상위 `v3`의 기존 검증 의존성도 먼저 설치해야 한다.

```powershell
Set-Location D:/Github/spotme-site/v3/motion-studies
npm ci
npm run build
npm run dev
```

서버를 켠 상태에서 별도 터미널로 실행한다.

```powershell
Set-Location D:/Github/spotme-site/v3/motion-studies
npm run verify
npm run render
# 이미 출력한 MP4를 다시 검사할 때
npm run quality
```

출력은 로컬 HyperFrames와 FFmpeg를 사용했다. Windows x64, Node.js 22.21.0에서 실행했다. 원격 렌더 서비스·API 키·클라우드 업로드는 사용하지 않았다. 직접 CLI를 사용할 경우 출력 경로는 현재 작업 폴더 기준이므로 `renders/spotme-a.mp4`처럼 지정한다.
