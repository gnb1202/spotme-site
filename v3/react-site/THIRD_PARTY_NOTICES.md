# SmoothUI Animated Tabs

Source: https://smoothui.dev/r/animated-tabs.json
Documentation: https://smoothui.dev/docs/components/animated-tabs
License: https://github.com/educlopez/smoothui/blob/main/LICENSE
Retrieved: 2026-09-27.

`src/components/smoothui/SmoothNavigation.jsx` adapts the component's shared-layout indicator, spring configuration and reduced-motion support. SPOT ME modifications: preserved source geometry/typography; page-navigation anchors and aria-current instead of tab-panel buttons; focus-only arrow-key navigation; hover/focus highlight and press response; plain scoped CSS instead of global Tailwind tokens. No new pages, labels or source artwork added. The Motion dependency supplies the runtime.
