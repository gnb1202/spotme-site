# Toss 레퍼런스 재현 비교본

2026-09-28 · 로컬 검토 전용 · `/concept/reference/`

## 목적과 범위

기존 `/concept/`는 SPOT ME로 재해석한 제안이고, 이번 비교본은 원본에 가깝게 확인하는 별도 페이지다. 기존 초안·실제 사이트·배포 설정은 교체하지 않는다. 배포 및 원격 업로드하지 않는다.

순서는 01 자산 기능 나열 → 02 금융 혜택 카드 → 03 쇼핑 앱 흐름이다. Toss 원본 문구·폰·카드·상품 이미지로 구성했다. 이미지와 폰트는 원본 공개 호스트를 참조한다. 저작권과 브랜드는 Toss 및 각 권리자에게 있으며 SPOT ME의 에셋으로 취급하지 않는다. 공개 배포 전에는 문구·이미지·폰트를 교체해야 한다.

## 확인한 자료

- https://toss.im/ 의 실제 DOM, 화면, 계산된 CSS.
- 브라우저에 제공되는 공개 JS/CSS를 `reports/toss-reference/public-source/`에 검사 자료로 보관. 앱 번들에 이 JS를 실행하거나 통째로 복사하지 않았다.
- 자산: `8539.5eea688c162aff57.js`, 금융: `6172.e9de240f0f55b183.js`, 쇼핑: `7020.e1b72ed49ebdf3ba.js`.
- 관련 공개 CSS: `142895a3d9d80b9a.css`, `6a94ed864ef38814.css` 및 자산 구간 스타일.
- 원본 저장소와 서버 코드는 접근하지 않았다. 공개 번들만으로 전체 기술 스택이나 내부 구현을 복제했다고 주장하지 않는다.

## 이전 시안과 달라진 점

1. 정면 앱 화면 교체 대신 1920×1080 기준 아트보드, 기울어진 폰 프레임과 개별 UI 카드 레이어 사용.
2. 자산 목록은 세로 강조선 대신 가로 구분선·아코디언. 선택 카드 x -30px, scale 1.05/1.1; 나머지 이미지 opacity .2. 전환 400ms, cubic-bezier(.6,0,0,.6).
3. 금융 카드는 간격 없는 3열, 아트 영역 500:600. 원본 배경 이미지·은행 로고·카드 앞/뒷면·보험 아이콘 사용. 금리 숫자 650ms 간격 갱신, 호버 시 결과 표시; 신용카드 720ms 3D 반전.
4. 쇼핑은 왼쪽 폰, 오른쪽 2개 체크포인트, 세로 가이드. 스크롤 시 할인 시트 → 쿠폰 → 포인트 → 밀기 → 완료 화면 연동.
5. 원본을 확인한 결과 자산·쇼핑 시퀀스는 주로 스크롤 기반이다. 별도 마우스 드래그가 원본 기능이라고 주장하지 않는다. 사용자 요청에 따라 결제 미리보기에는 직접 좌우 밀기와 Enter/Space 대안도 추가했다. 실제 결제는 없다.

## 일치와 남은 차이를 구분

원본 수치와 에셋을 기반으로 재현했지만 픽셀 단위 완전 복제는 아니다. 전체 Toss 페이지 앞뒤의 영상과 전환은 포함하지 않았다. 원본의 자산 배경 입자, 일부 세부 Lottie 효과, 쇼핑 진입 시 중앙 폰에서 왼쪽으로 이동하는 긴 앞부분은 현재 비교본에서 생략했다. 쇼핑 완료 화면의 일부 UI는 독립 HTML로 재작성했다. 모바일은 잘림 방지를 위한 별도 대응이며 원본 모바일과의 일치 검증은 아니다.

이번 비교본을 승인한 다음에만 SPOT ME 기능·멘트·실제 화면을 각 시퀀스에 매핑한다. 금융 문구를 운동 효과로 단순 치환하거나 존재하지 않는 앱 기능을 만들지 않는다.

## 검증

- Next.js 프로덕션 빌드: 통과 (18개 정적 페이지).
- 실제 브라우저에서 1440×1000 비교, 에셋 로드 오류·가로 넘침 검사.
- 자산 아코디언 클릭 및 선택 카드 전환 확인.
- 금융 카드 클릭/호버 후 금리 분석 완료·최저 4.60% 및 은행별 결과 표시 확인.
- 쇼핑 시트에서 184px 오른쪽 드래그 후 주문 완료 화면 표시 확인. 실제 결제 API는 없다.
- 390×844에서 자산 첫 화면과 가로 넘침 없음 확인. 전체 모바일 정밀 일치 QA는 별도다.
- 개발 브라우저 콘솔 오류/경고 0개. 공개 외부 이미지 로드 실패 0개.
- 측면 비교 구간 링크는 즉시 이동한다. 구간 내부 모션은 유지한다.
- 캡처: `reports/toss-reference/shopping-drag.png`, `reference-finance.png`.

## SPOT ME 팔레트 적용 (2026-09-29)

사용자 요청으로 같은 비교본의 색상만 SPOT ME로 변경했다. 별도 `spotme-palette.css`에서 적용하며 구조·서체·카피·모션은 유지한다. 긴 배경 그리드 3개는 앞선 요청대로 제거된 상태다.

- 색상 근거: 현재 동결된 `v3/designs/figma-data.json`의 SOLID fill. 민트 #5EEFD3, 배경 #FAFAF8, 검정 #0A0A0A, 본문 #343A40, 회색 #61656A / #919EA5, 보조 핑크 #EF5E7A.
- 파란 인터랙션 강조를 민트로 변경하고 민트 위 글자는 차콜로 표시해 대비를 확보했다.
- 금융 카드의 원본 배경 질감은 CSS로 무채색화한 후 브랜드 색 바탕과 합성했다. 원본 이미지 파일 자체는 편집하지 않았다.
- 실제 앱 화면·은행 로고·카드 이미지에 포함된 색상은 변경하지 않았다. 기능 콘텐츠를 SPOT ME로 바꾸는 작업은 아직 아니다.
