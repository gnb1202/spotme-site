# 레미와 함께 — 실제 앱 기반 시퀀스

2026-09-29. 로컬 `/concept/?preview=remi-journey#remi-sequence` 전용. 배포/푸시 없음. 앱 저장소는 읽기만 했다.

## 이번 변경

기존 간략한 3장 데모를 9개 상태로 교체했다. MY GYM·TIER·REPORT와 다른 페이지는 유지했다. 기존 프로젝트 개선 스킬에 따라 Next/React/Motion을 유지하고 새 모션 라이브러리는 추가하지 않았다.

1. 오늘의 루틴 → 민트빛 스윕·별빛과 함께 AI 추천 목록 공개.
2. 운동 화면의 마이크에 컬러 포커스 → 실제 레미 음성 팝업 → 세트 중량 수정 → 변경한 값으로 운동 화면 복귀.
3. 마지막 세트 공격 → 슬라임 처치 → 운동 완료 → 결과 요약.

데스크톱은 640svh 구간에서 폰과 설명을 고정하고 자연 스크롤로 전환한다. 휠 이벤트를 가로채지 않는다. 세 가지 설명과 내부 단계 버튼으로 구간을 건너뛸 수 있다. 좁거나 낮은 화면(900px 이하 또는 높이 700px 이하)은 긴 고정 스크롤을 해제하고 폰/단계/이전·다음 버튼으로 진행한다. 모션 감소에서도 수동 전환을 제공하고 스윕·별빛·공격 이동·회전을 생략한다.

## 예시 시나리오 / 범위

- 실제 AI 서버나 마이크 권한을 사용하지 않는다. 음성·입력 데이터 저장/전송도 없다.
- 음성 요청은 미리 준비한 `체스트 프레스, 15kg으로 낮춰줘` 예시이며 사용자의 자유 발화를 인식하지 않는다.
- 중량/횟수 조작은 로컬 상태에 반영된다. `남은 세트 통일`을 누르면 다음 운동 카드에 같은 값이 표시된다. 다시 보기를 누르면 15kg/14회 초기값으로 돌아간다.
- 5종목·20세트, 46분 및 날짜는 설명용 고정 예시다. 중간 운동을 생략하고 마지막 공격을 보여준다는 안내를 넣었다.
- 앱의 모든 입력/필터/추천 피드백 기능을 복제한 것은 아니다. 이번 작업 대상은 지정된 소개 시퀀스다.

## 검증

- 37개 원본/변환 파일 해시 및 자산 HTTP, 기존 7개 경로 응답 검사 통과.
- 프로덕션 빌드 18페이지 생성 통과.
- 브라우저에서 마이크 클릭 → 음성 예시 팝업 확인.
- 키보드 Enter로 추천 → 운동 → 음성 → 편집 → 적용 → 결과 → 초기화 확인.
- 중량을 15.5kg으로 올리고 반영한 후 실제 운동 카드의 `15.5kg` 확인.
- 자연 스크롤로 마지막 공격/완료 전환 확인. 모든 현재 화면 이미지 로딩 완료.
- 390×844 뷰포트에서 폰 너비 320px, 가로 오버플로 없음, 초기화/추천 전환 확인. 검증 후 뷰포트 재설정.
- 모션 감소는 코드상 분기 확인. OS 설정을 바꿔 실행한 검증은 하지 않았다.
- 캡처: `reports/experience/remi-routine.png`, `remi-set-editor.png`, `remi-mobile.png`.
