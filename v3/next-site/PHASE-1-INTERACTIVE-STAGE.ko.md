# Phase 1 — 탭 전환 · 홈 1회 오프닝 · 레미 AI 무대

## 승인 범위

2026-09-29 요청 4개를 로컬에서 구현한다. 기존 Next.js/React/Motion/GSAP를 유지하고 새로운 라이브러리, AI API, 개인 정보 입력을 추가하지 않는다. 디자인 개선 스킬에 따라 기존 실제 답변/에셋/색상 시스템을 재사용한다. 배포와 Git push는 포함하지 않는다.

## 구현

1. 공통 탭 전환: 클릭 시 크림 블랙 로딩 덮개를 표시한다. 라우트 마운트 후 폰트와 첫 화면 이미지 디코딩을 기다리며 최소 320ms 로딩 표시를 둔다. 준비 후 도착 페이지 테마색이 왼쪽에서 펼쳐지고 덮개가 오른쪽으로 빠지며 콘텐츠가 20px 슬라이드 인한다. 홈 민트, 기능 화이트, 레미 AI/시연 크림 블랙. 전환 중 콘텐츠 inert 처리, 연속 입력 방지, 새 탭용 수정키 유지. 오류 시 12초 뒤 다시 불러오기/닫기 제공. 모션 감소 설정에서는 색상 확장·슬라이드를 생략한다.
2. 홈 오프닝: 완료/건너뛰기 시 sessionStorage에 기록한다. 같은 브라우저 탭의 재방문/새로고침에서는 생략하며 새 세션에서는 재생한다. 저장소 차단 환경은 메모리 폴백을 사용한다. 기존 홈 스크롤 충전은 유지한다. 탭 전환 덮개 아래에서 오프닝이 먼저 재생되지 않도록 전환 종료 이벤트까지 일시 정지한다.
3. 레미 AI: 크림 블랙과 민트, 기능 탭의 Pretendard를 사용한다. 왼쪽 설명/4개 기능 선택과 오른쪽 큰 휴대폰으로 구성한다. 휴대폰 속 4개 버튼과 왼쪽 선택 모두 루틴 생성·운동 추천·기록 피드백·식단 추천의 기존 준비된 답변을 표시한다. 순차적으로 등장하는 답변 항목, 처음으로/다른 질문, 내부 스크롤, 키보드 포커스를 제공한다. 실제 AI 요청은 없다고 명시한다. 기존 기능 탭의 AI 데모는 삭제하지 않는다.
4. 홈 타이포: 원본 생성 JSON은 보존하고 scoped CSS로 소개/설명/사용법에 기능 탭의 SpotExperience(Pretendard)·굵기·행간·자간을 적용한다. ABOUT 제목·본문 크기와 공간을 조정하고 HOW TO USE와 단계 숫자를 같은 글꼴로 통일한다. 오프닝 외곽선과 연결되는 SPOT ME MY WORKOUT 로고 타이포는 보존한다. 기존 홈 캔버스 기반 레이아웃을 완전히 재구성하지 않는다.

### 후속 예외: 시연 영상은 기존 시안 유지

사용자 요청으로 시연 영상에 한해 위 민트 리컬러를 취소했다. 원본 배경 두 레이어의 불투명도 1, 흰 제목, 검정 푸터, 투명 헤더/흰 메뉴를 복구하고 탭 전환 도착색도 기존 크림 블랙으로 되돌렸다. 기능/레미 AI 민트 및 공통 로딩 동작, YouTube 클릭 후 임베딩은 유지한다. 브라우저 계산 스타일과 통합/팔레트 검사 PASS. 로컬만 반영.
