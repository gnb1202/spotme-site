# PHASE 0 — 사이트 통합 및 마이그레이션

## 승인된 범위

- 기존 민트 홈과 A안 인피니티 미러 오프닝, 스크롤 충전 모션을 복원한다.
- 공통 메뉴를 홈(`/`), 기능(`/features/`), 레미 AI(`/remi-ai/`), 시연 영상(`/video/`)으로 통합한다.
- 현재 운영의 기능 시안을 기능 페이지로 이동한다. 레미 AI 전용 디자인이 준비되기 전에는 기존 상호작용을 삭제하지 않는다.
- 레미 AI는 크림 블랙 테마의 빈 경로만 확보한다. 디자인과 콘텐츠 이전은 다음 단계로 보류한다.
- 시연은 Figma의 기존 영상 페이지를 재사용하며, 사용자가 제공한 YouTube 영상 `biQ6ug9MgCs`를 클릭 후 임베딩한다. 파일 업로드, 새 영상 제작, 자동재생 진입은 없다.
- 해당 영상은 졸업작품 영상으로 표시되며, 사용자가 시연용 임시 영상으로 사용한다고 확인했다. 최종 시연 영상은 `src/integration/navigation.js`에서 교체한다.
- 로컬 구현만 수행한다. 배포, 커밋 및 원격 푸시는 별도 요청이 필요하다.

## 세부 단계 및 완료 기준

1. 기준본 확인: `src/generated/motion.json`, 두 runtime, `pages/home.json`, `pages/video.json`, 동결된 `../designs/figma-data.json`을 기준으로 삼는다.
2. 경로 통합: 네 메뉴의 직접 접근, 현재 위치 표시, 뒤로 가기 및 홈 재진입을 확인한다.
3. 홈 복원: 오프닝 이후 기존 좌표의 홈이 나타나고 충전 후 다음 섹션으로 이동해야 한다. 페이지 이탈 시 이벤트 및 스크롤 잠금을 해제해야 한다.
4. 영상 연결: 최초 로드에는 iframe이 없고, 재생 버튼을 누를 때만 생성한다. 기존 검은 영상 영역과 레미 그림은 썸네일로 재사용한다. 기존 ‘추후 공개 예정’ 문구만 재생 버튼으로 바꾼다.
5. 보존 검증: 전달 에셋, 원본 데이터, 기능 데모 유지 여부와 빌드를 검사한다. Figma 기준 측정과 새 승인 변경의 기능 검증을 분리해 기록한다.

## 구현 및 검증 기록 — 2026-09-29

### 구현 결과

- `/`는 보존된 A 오프닝과 홈을 기본 실행한다. `?intro=skip`으로 오프닝만 건너뛸 수 있으며, `?experience=static`은 원본 구조 측정용이다.
- `/features/`는 기존 기능 시안 전체를 재사용한다. `/concept/`는 기존 비교 링크 보존을 위해 남겼다.
- `/remi-ai/`는 공통 메뉴와 크림 블랙 바탕만 제공한다. 신규 카피, 기능 및 디자인은 추가하지 않았다.
- `/video/`는 기존 프레임과 에셋을 사용하고, `254:38` 영상 영역만 클릭형 임베딩으로 교체했다. 클릭 전 iframe 0개, 클릭 후 재생 진행(0:19/5:11)을 확인했다. 다른 탭으로 이동하면 iframe이 제거된다.
- 공통 메뉴는 단일 컴포넌트로 구성했다. 기존 5개 메뉴는 렌더링하지 않으며, 직접 경로와 현재 메뉴 표시를 지원한다. 이전 AI/게임/캐릭터 상세 URL은 삭제하지 않았다.
- 기능 페이지 이탈 중 ResizeObserver가 제거된 요소를 읽던 오류를 수정했다. 홈 모션 정리 시 전역 선택자 대신 보존된 요소를 사용하도록 수정했다.
- 홈 모션 로딩 중 검은 화면을 유지하고, 원본 대비 변경한 네 메뉴는 작은 화면에서 두 줄로 배치한다.

### 실제 검증

- `node scripts/check-integration.mjs`: 4개 경로 HTTP 200, 동결 Figma SHA-256 유지, 원본 핵심 5개 노드의 소스 좌표 오차 최대 0.003415px.
- `node scripts/check-experience.mjs`: 51개 기능 에셋 무결성 및 7개 경로 검사 PASS.
- 1920px 실제 DOM: 홈 타이포 `(17,327,1887,396)`, 레미 `(640,285,642,480)`, 설명 `(585,807,751,39)`로 원본과 일치. 타이포 180px, 설명 30px. 폰트 로드 완료 및 실패 이미지 0개.
- 영상 실제 DOM: 플레이어 영역 `(40,2951,1840,1036)`. 클릭 전 iframe 없음. 원본 비율 유지.
- 홈 자동 오프닝 완료 후 `charging`, 다음 섹션 조작 후 `released`, 스크롤 잠금 해제, 다음 섹션 상단 0px 확인.
- 홈에서 기능 탭으로 이동한 후 모션 DOM 제거 및 body 잠금 해제 확인. 레미 AI의 비어 있는 main과 `rgb(52,58,64)` 배경 확인.
- 390px 메뉴: 4개 링크가 모두 화면 안에 들어가며 수평 넘침 없음. 헤더 높이 100px. 전체 모바일 리디자인 검증은 제외했다.

### Mimikyu 미완료 게이트

- 전체 정적 캡처는 `reports/integration/home-full.png`, `video-full.png`에 저장했다.
- 캡처 도구가 홈을 1904×5304, 영상을 1904×4426으로 반환했다. 기존 구현 비교본은 각각 1920×5305, 1920×4426이다.
- `compare.py`는 크기 불일치로 정상적으로 실패했다. 비교를 통과시키기 위한 확대·축소·크롭은 하지 않았다.
- 동결 Figma PNG 자체도 홈 381×1024, 영상 445×1024인 저해상도 자료다. 기준 JSON은 그대로 유지했다.
- 따라서 전체 및 9개 영역 99% 픽셀 일치, 전체 TEXT 노드 구조 검증 통과는 **미확정**이다. 위 핵심 노드 DOM/소스 검사와 기능 QA를 전체 Mimikyu 통과로 대체하지 않는다.
- 남은 검증: 동일 해상도의 원본 PNG와 정확한 전체 화면 캡처 환경에서 픽셀 비교 및 전체 구조 검증. 신규 승인 메뉴/영상 컨트롤은 기존 Figma와 별도 승인 영역이다.

운영 사이트 및 원격 저장소에는 이번 변경을 반영하지 않았다.

## 후속 수정 — 헬스장 성장 스크롤

사용자 요청에 따라 기능 페이지 첫 소개의 헬스장 이미지를 스크롤 진행량에 직접 연결했다. 기존에는 구간의 52%를 넘어서면 시간 기반으로 한 번 전환했다. 수정본은 구간 0–12%에서 파괴된 헬스장을 유지하고, 12–50%에서 기존 `gym-after.webp`가 점차 나타나며, 나머지 구간에서는 복원된 헬스장을 유지한다. 위로 스크롤하면 동일한 진행량을 거꾸로 적용한다. 별도 타이머, 자동 반복, 새 에셋 또는 문구는 추가하지 않았다. 두 번째 섹션의 MY GYM hover 카드는 변경하지 않았다.

- `node scripts/check-gym-progress.mjs`: 시작/중간/완료/역방향/범위 검사 PASS.
- 브라우저에서 헬스장 구간 활성 상태로 opacity 0, 0.252367, 1을 확인했다. 두 에셋 로드 완료 확인.
- 모션 감소 설정에서는 복원된 이미지를 즉시 표시하는 기존 정책을 유지했다.
- `npm run build`: 20개 페이지 빌드 성공. 배포하지 않았다.
- 캡처: `reports/integration/gym-scroll-before.png`, `gym-scroll-after.png`.

## 후속 수정 — 3회 충전 후 레어까지 진화 (2026-09-29)

### 추가 피드백 반영

- 표시 문구의 ‘1단계’와 성장 알림의 중복 RARE를 제거하고 상단 등급 라벨을 카드 50% 위치에 중앙 정렬했다.
- 전방 스크롤로 성장 단계가 올라갈 때만 850ms 민트 링·빛 확산·광택·8개 반짝임을 1회 재생한다. 레어는 1초, 금빛을 더한 12개 반짝임으로 강조한다. 전체 화면 점멸이나 흔들림은 없다.
- 완료 이벤트로 효과 DOM을 제거한다. 역스크롤·비활성 섹션·모션 감소는 재생하지 않고, 연속 진화는 최신 효과로 교체한다. 스크롤 및 기존 충전/에셋 진행은 그대로 유지한다.
- 조건 단위 검사와 20개 페이지 빌드 PASS. 브라우저에서 레어 효과 클래스/12개 반짝임 생성, 완료 후 DOM 0개, 콘솔 오류 없음 확인. 캡처 `reports/integration/gym-growth-impact.jpg`. 로컬만 반영.

- 앞선 단일 복원 전환을 대체했다. 헬스장 스크롤 구간 8–62% 안에서 0→100% 충전을 3회 반복하고, 각 충전 완료 뒤 노멀 02 → 노멀 03 → 레어 01로 진화한다. 100% 유지 구간을 두어 충전 완료가 보인 뒤 에셋을 전환한다. 나머지 구간에서는 레어·100%를 유지한다.
- 원본 `스팟미_260920_v1/05_운동/02_헬스장키우기/헬스장_노멀_03.png`, `헬스장_레어_01.png`를 비율 유지 WebP로 추가했다. 정확한 경로와 SHA256은 에셋 manifest에 기록했다. 기존 두 에셋과 두 번째 MY GYM 카드는 유지했다.
- 2층 이미지 전체가 보이도록 이미지 영역을 높이고 contain/bottom 정렬했다. 성장 알림은 이미지 위 여백에 배치한다.
- 이름과 비용은 앱 gym-v6-spec.json/gym-stages.json을 참조했다. 데모 재화 350은 세 차례 비용 50+100+200의 합이며, 실제 잔액이나 API와 무관하다. 역스크롤은 같은 상태를 역방향 재현하고, 모션 감소 시에는 레어 완료 상태를 바로 표시한다.
- 단위 검사 PASS: 세 차례 충전, 100% 후 진화, 레어 유지, 재화 범위, 역방향. 에셋 53개 해시/HTTP 검사 PASS. 20개 페이지 프로덕션 빌드 PASS.
- 브라우저에서 두 번째 충전 17→100%, 다음 단계 21%, 레어 100% 및 에셋 4개 로드를 확인했다. 전체 PC/모바일 QA나 Figma 픽셀 비교는 이번 수정 범위가 아니다. 배포·원격 반영하지 않았다.
